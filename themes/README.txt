Drop one photograph per theme here, named exactly:

  electricity.jpg    transport.jpg
  telecom.jpg        social.jpg
  water.jpg          admin.jpg

Landscape, around 900 x 600, under 300 KB each. Use RSA's own field or
satellite imagery; do not take pictures from the web without a licence.

If a file is missing the card falls back to drawn artwork, so nothing breaks.

To give one dataset its own picture instead of the theme photo, add a custom
property named coverImage to that table in OpenMetadata and put an image URL
in it, then expose it in catalogue_api.py.
